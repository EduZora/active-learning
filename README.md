# بوصلة التعلّم النشط | Active Learning Compass

دليل تفاعلي ثنائي اللغة يضم 122 استراتيجية للتعلّم النشط، وكتابًا تفاعليًا بالعربية والإنجليزية، ونسختي PDF، وأدوات للبحث والتصفية والمفضلة والتخطيط والمقارنة والحفظ المحلي.

## معاينة الموقع

- يبدأ الموقع بالعربية من `dist/index.html`.
- الإنجليزية من زر **English**، والعودة للعربية من زر **AR**.
- ملفات الواجهة والبيانات محلية، ولا تتطلب مفتاح API.
- افتح `dist/booklet-ar.pdf` أو `dist/booklet-en.pdf` لتنزيل النسخة المناسبة. يمكن أيضًا تصفح الكتاب التفاعلي من داخل الموقع.

## الرفع إلى GitHub Pages

المستودع مهيأ للنشر إلى GitHub Pages باستخدام GitHub Actions:

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. من **Settings → Pages** اختر **GitHub Actions** كمصدر للنشر.
3. ادفع التغييرات إلى الفرع `main`؛ يتولى سير العمل نشر مجلد `dist`.

للنشر اليدوي، استخدم محتويات `dist` بوصفها جذر الموقع. حافظ على المجلدات والملفات كما هي، خصوصًا `assets` و`icons` و`qr` وملفات PDF.

## فحص الجودة

نتائج اختبار النسخة الثنائية v9 وحدود الاختبارات السابقة في [QA-BILINGUAL-v9.md](QA-BILINGUAL-v9.md). أضيفت تحسينات بصرية طفيفة ضمن الإصدار 9.1 وتصحيح تحرير في وصف الصفحة واسم المُعدّة، مع إبقاء المحتوى والوظائف الأساسية على حالها.
